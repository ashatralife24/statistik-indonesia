Statistik Indonesia — portal ringkas data nasional dari publikasi resmi Badan Pusat Statistik (BPS): penduduk, ekonomi, harga (inflasi), ketenagakerjaan, kemiskinan, dan daerah. Setiap angka disertai sumber dan tahunnya; tidak ada angka karangan. Situs statis tanpa build step dan tanpa network request: grafik digambar dengan canvas polos, navigasi memakai hash routes, dan layout berjalan di desktop maupun phone.

## Run it

```sh
node serve.ts
# buka http://localhost:8080
```
